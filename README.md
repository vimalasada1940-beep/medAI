# MediPulse 🏥⚡

> **Medicine Stock-Out Early Warning & Smart Redistribution for Primary Health Centres (PHCs)**

MediPulse is a beginner-friendly, student decision-support prototype designed to track medicine inventories across multiple Primary Health Centres (PHCs), compute daily burn rates, forecast stock-out risk, flag rapid consumption accelerations, recommend safe inter-PHC stock transfers, and generate emergency indents.

> **Disclaimer**: This is a student decision-support prototype built for demonstration and research purposes. It is **not** a clinically validated or officially deployed government system. Automated transfers are disabled; all actions require human authorization.

---

## 🏗 System Architecture & Technology Stack

- **Frontend**: React (Vite), JavaScript, Vanilla CSS, Recharts, Lucide Icons.
- **Backend**: Python 3.11/3.12, FastAPI, SQLAlchemy, Pydantic v2.
- **Database**: PostgreSQL (managed via pgAdmin).
- **ML / Data**: pandas, NumPy, scikit-learn, joblib.
- **Testing**: pytest.

## ⚡ Quick Setup Instructions

1. **Backend Setup**:
   ```powershell
   cd backend
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   cp .env.example .env
   # Edit .env to set your PostgreSQL credentials
   python -m database.seed
   uvicorn app.main:app --reload --port 8000
   ```

2. **Frontend Setup**:
   ```powershell
   cd frontend
   npm install
   npm run dev
   ```
